# Geometry 0.16.0 qualification

The material-partition adapter rounded inputs to Float32 but validated ancestry against the original doubles. Four captured deformed tree inputs therefore failed strict source-triangle checks. `createManifoldMesh64` restores original coordinates through native warp before Boolean work, with bounded validation and explicit rejection of ambiguous rounding or topology-count changes. The partition adapter now uses it. No ancestry or geometric tolerance is relaxed.

79 package tests pass (31,615 assertions). New checks cover exact vertices, face/source identities, caller-array immutability, ambiguous/nonfinite/index rejection, native-handle cleanup and four captured deformed trees. A GPU-disabled Chromium module worker loads real Manifold WASM and the built package; eight cube vertices remain exact and all four captured partitions pass. The first browser harness run failed because its module-filename allowlist excluded digits; allowing `createManifoldMesh64.js` fixed the test router, with no package change.

Game matrix: partition import alone improves 119/168 accepted to 143/168. Remaining 25 cases still fail, and the matrix correctly remains failed overall. Applying this helper to every later cut is NOT qualified: 140/168 pass with 28 rejections (including nine ambiguous Float32 imports). That experimental game preload must not be shipped as an accepted cut-path change. The API is deliberately strict rather than hiding unresolved thin shells. Geometry qualification does not certify colliders, gameplay motion, drag or all tree variants.

Primary references checked 2026-10-31: [Mesh API](https://manifoldcad.org/docs/jsapi/classes/manifold.Mesh.html) and [precision caveats](https://manifoldcad.org/docs/jsuser/); installed manifold-3d 3.5.1 implementation/type definitions were checked for the actual wrapper behavior. Native warp callback errors are deferred until after return so the pinned wrapper can release its callback-table slot.

The game candidate passes all 922 maintained tests (7,501,835 assertions). Two independent TypeScript builds match all 42 shipped dist files. All 45 extracted archive files match source/build outputs, and the extracted native-import consumer preserves exact vertices. Existing browser-worker consumers also pass with GPU disabled. Initial npm packing encountered the sandbox's read-only default cache; rerunning with a workspace cache succeeded. No artifact from that failed attempt is used.
